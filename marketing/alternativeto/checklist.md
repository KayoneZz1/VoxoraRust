## Rejection risks and mitigations

| Risk | Mitigation |
|---|---|
| Saturated soundboard category / “indistinguishable” | Lead with free + MIT + no account + native Rust + radial menu + portable build; keep the honest limitations visible |
| Description contains a URL | URLs only in the Website/download fields |
| App not in English | English UI and English screenshots are included |
| Missing icon or screenshots | 512 px icon and four real screenshots prepared |
| Private beta / unreleased | Public 1.0.0 release with working installer and portable build |
| Claims that cannot be verified | No CPU/RAM percentages; performance is described only as binary size and technology |
