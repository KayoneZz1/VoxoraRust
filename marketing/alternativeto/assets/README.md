# Screenshot captions and specifications

All screenshots were captured from the real Voxora Rust 1.0.0 interface on Windows 11 using a clean test profile. The library contains six generated test tones named Airhorn, Victory, Applause, Bomb, Laugh and Intro. No personal sound names, desktop files or account data are visible.

| File | Size | Suggested caption |
|---|---:|---|
| `main.png` | 1346×781 | Main window with local sound cards, categories, favourites, per-sound volume and global hotkeys. |
| `settings-audio.png` | 1346×781 | Audio routing: virtual-cable output, microphone and optional local monitor. |
| `settings-general.png` | 1346×781 | Settings: theme, language and startup behaviour. |
| `onboarding.png` | 1346×781 | First-run setup with language, theme and audio routing. |
| `icon-512.png` | 512×512 | Application icon (transparent PNG, derived from the shipped app icon). |

The screenshots have the OS title bar cropped so only application content is shown. They are PNG, under 3 MB each, and contain no animation.
