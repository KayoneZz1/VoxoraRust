# AlternativeTo submission pack

This directory contains everything needed to submit **Voxora** to AlternativeTo. Nothing has been submitted and no AlternativeTo account was created.

- `submission.md` — copy-paste values for the form and the manual steps
- `description.md` — English short/full descriptions, features, requirements, limitations
- `competitors.md` — verified comparison with Soundpad and Voicemod, including gaps
- `checklist.md` — pre-submission, user-action and post-approval checklist
- `assets/icon-512.png` — 512×512 transparent PNG based on the shipped application icon
- `assets/main.png` — real English main-window screenshot with a clean six-sound test library
- `assets/settings-audio.png` — real audio-routing settings screenshot
- `assets/settings-general.png` — real general settings screenshot
- `assets/onboarding.png` — real English first-run setup screenshot

## Current status

Prepared for manual submission. The remaining steps require the account owner:

1. Sign in / sign up at AlternativeTo and verify the email.
2. Use **Suggest new application** from the user menu.
3. Fill the form from `submission.md`, upload the icon and screenshots.
4. Submit; optionally pay for priority review only with explicit approval.
5. After approval, suggest Voxora as an alternative on Soundpad and Voicemod.

## Important product facts

- Rust edition: **1.0.0**, MIT, Windows 10/11 x64.
- Original C# edition: **2.2.1**, MIT, separate repository.
- **VB-CABLE is required** for voice-chat routing; Voxora does not install a virtual audio driver.
- No recorder/editor, community sound library or AI voices.
- Builds are unsigned; SmartScreen may warn.
- The English UI is usable, but a few status strings may remain Turkish.

Do not add links, email addresses or phone numbers to the description fields; AlternativeTo rejects them.
